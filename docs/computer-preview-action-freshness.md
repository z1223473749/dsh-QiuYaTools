记录日期：2026-10-23。此修复覆盖共享预览页面，不等同于 Mac／Windows 整包、真实模型或原生输入验收完成。

## 问题和改动

人工点击目标画面时，后台可能已经请求了下一张预览图。如果该图在点击执行期间返回，它会先成为可输入帧；但点击完成时生产会话会清除此前所有帧，随后文字／Enter可能使用刚被清除的frameId并被Host拒绝。旧页面还会在正常刷新时清掉操作错误，用户只看到文字仍留在footer。

现在人工操作开始就使当前帧和此前的异步画面失效，操作未结束时不接受重复点击、文字或Enter，也不请求新的可操作帧。完成或失败后重新取得当前画面才启用下一次输入。暂停／接管／停止仍可中断控制，旧画面和迟到回执不能恢复输入；没有自动重放业务动作。

操作错误与画面连接状态分别保存，成功刷新只清连接提示，操作错误保留到用户下一次明确操作。缺少可用画面时提示等待刷新。
