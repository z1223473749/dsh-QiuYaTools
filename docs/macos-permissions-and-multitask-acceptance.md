# Mac 权限归属与同聊天多任务验收

本轮在会话环境入口的基础上，完成 Mac 权限执行器、紧凑授权卡片及同一聊天多个操作任务的接线。安装包保存在仓库外，未发布到 npm、GitHub 或其他远端。各包 SHA256、测试 JSON、原始日志及成功截图由本次本地交付清单索引。

## 修改及行为

- Mac 默认执行器由 LaunchServices 启动 `QiuYaTools Computer.app`。旧版直接从 Harness 派生进程，系统会将权限归责给 Harness；用户给独立插件应用打开开关时，旧进程的预检仍可返回未允许。相同已安装应用和签名的只读对照实际重现了这一差异。
- 设置面板的权限查询改为同一读取周期只保留一个在途请求，定时轮询和手动重新检查共用结果。旧实现每 1.5 秒作废前一次读取，慢查询即使返回已允许也可能一直不显示；新增回归先复现失败，再验证 6 秒慢响应、手动刷新、失败重查、切换会话及关闭后的隔离。
- Host 与执行器通过私有 Unix socket 通信，握手核对一次性随机值、Bundle ID、Host PID、实际执行器 PID 和出生标识。启动取消不发送排队命令；正常退出需同时确认输入已释放、采集已停止、socket EOF 和系统启动器正常退出。退出不确定时继续阻止替换输入。
- 授权卡片缩为 320×84，仅有真实应用图标、名称和拖拽提示。卡片跟随系统设置窗口，切到其他应用时隐藏；拖动导出真实 `.app` 文件 URL。安装版实际卡片截图只含卡片本身。真实跨应用拖放的完整回执本轮未取得，不以 UI 截图或纯逻辑测试替代该项。
- 每个聊天包含默认任务及最多 7 个具名任务。模型在会话中创建任务，再明确传入 Host 返回的 `taskId`。目标、一次授权、观察帧、控制周期与预览分别隔离；同一实际桌面的鼠标键盘仍使用共享 FIFO。
- 小预览位于当前会话右上方，固定长方形、画面铺满并带阴影；多个任务显示编号切换入口。其余控制在悬停或键盘聚焦时出现，允许单独弹出。正式会话的公开 overlay 插槽和 mounted-session 订阅覆盖空白会话及已有消息会话，保留 Harness 自有的侧栏入口。
- 新任务的普通操作不会写入默认任务的自动验收账本。现有 H1/H2 工作流继续沿用默认任务的模型目标边界。
- 聊天内预览和弹出面板共用同一视图的读取状态。暂停、接管、继续或停止发出前同步取消旧读取；停止确认后，旧状态、晚到画面和未更新的缓存不能重新启动轮询。控制失败或结果未知时只读取新状态确认，不重放控制，也不影响其他任务。
- 浏览器读取画面时，对同一 CDP session 临时启用低分辨率截图流并逐帧确认，保持后台页面的绘制表面活动；流画面只用于确认，不交给模型或预览。每次调用仍返回原来的独立 JPEG 截图，参数与 15 秒传输期限保持不变。最后一个读取退出时确认停止与全部帧回执；取消、关闭标签页、批注通道和整个环境均等待相应读取退出，未知清理结果不会被当作成功。不同浏览器实例的观察帧 ID 也加入独立随机命名空间。

## 2026-10-26 权限自动检测与恢复修复

后续实际重现了两个独立问题：同名系统权限条目的开关可以为开启，但当前执行器的系统检查仍返回未授权；系统设置的“退出并重新打开”会让旧的纯权限检查执行器缺少正常清理回执，旧 Host 随后永久阻止连接替代进程。Mac 设置页没有显示这一连接错误，而是将缺失读数显示成“待检查”。前者不能通过配置伪造授权，后两者已在本次代码中修复。

- 设置页保留定期检查，并在窗口恢复焦点或可见时立即刷新。读取失败会失效旧读数，明确显示“无法检查”和失败原因；不再把连接失败当成未授权，也不会保留旧的“已允许”。辅助功能已获 AX 授权但事件发送检查失败时单独说明原因。
- 仅发送过权限状态、系统设置、应用目录或窗口目录请求的执行器，在私有 socket 已关闭、系统启动器正常退出、操作系统确认认证 PID 不存在后，可自动重新连接。已经使用输入、采集、预览或控制租约的执行器仍要求完整清理回执；未知清理结果继续阻止替代输入。只有状态读取可在确认退出后重读一次，任何输入或设置操作均不重放。
- 原生构建增加完整输入指纹及应用完整性、严格签名校验。未改变原生构建输入时复用原应用，不重新编译或签名；缺少构建记录、输入变化、文件被改或签名失效时均重新构建，缓存不进入发行包。

用户确认后已重新建立本机输入监控、辅助功能和屏幕录制授权。其中屏幕录制原先没有当前应用条目。独立 LaunchServices 新进程实际返回 `screenRecording=true`、`accessibility=true`、`postEvents=true`、`inputMonitoring=true`。修复包通过官方插件管理器安装，包内 21 个文件与安装目录逐字节一致，原配置及已有应用授权记录哈希未变，原生 universal 程序 SHA256 保持 `1ac53af2a5d2228840a0d29c98f0c9a376094aae6bc674224fb0aee8680681cd`。
