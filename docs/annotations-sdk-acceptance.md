# 会话画面批注接线与验收

工作台中的「批注画面」使用当前聊天、当前应用和当前画面版本。用户可以框选、画箭头、添加文字，或只读选择网页元素；点击「发送到当前聊天」后，带批注的 PNG 和说明才会通过 Harness 的公开 Session／Attachment 接口交给模型。取消草稿不产生聊天消息或模型图片。

网页元素定位使用 Host 创建的只读隔离环境，不向模型提供网页脚本执行接口，也不修改目标网页的 DOM 或样式。滚动后回到相同像素、页面导航、停止任务或撤销授权，都会使旧画面失效。旧草稿不能靠相同截图继续发送，必须重新截取。
