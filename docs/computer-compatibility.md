# 电脑操控兼容性

## 权限兼容

Windows 普通模式会在输入前读取目标完整性级别。高权限目标返回 `administrator-required`，不会把权限失败等同于窗口失效或自动重发。

用户先停止现有控制，再在电脑操控的系统权限区域选择“启用管理员访问”，并在目标 Windows 桌面确认 UAC。独立助手只开放状态、应用发现、观察、租约和输入；应用启动、任意命令及网页预览不进入提权进程。主界面和网页预览继续使用普通权限。

提权通道使用同一用户的随机命名管道，双向核验进程身份。取消 UAC 不改变普通模式。切换后需重新观察和获取控制；安全桌面、跨用户提权和受系统保护的目标不承诺可控。普通和提权助手共用桌面锁；输入日志允许正常的跨权限交接，守护进程继承输入所有者权限。退出必须确认提权助手已释放输入，否则保持故障状态。

验证：TypeScript 类型检查、权限入口与原生协议测试、生产提权传输的独立 .NET 行为测试、Windows ARM64 编译。传输测试不产生系统输入。真实 UAC、跨权限桌面输入和异常恢复仍需 Windows 交互环境验收。
