# 浏览器授权与验收记录连接身份修复

本单元修复两项真实 Harness 验收中发现的产品问题。代码、回归和构建一起交付，完整产品视觉验收继续保留未通过状态。

## 行为变化

Mac 的独立浏览器通道报告 `mode: browser`、捕获与输入能力可用，桌面 TCC 字段为空。旧界面仍要求屏幕录制和辅助功能权限，导致“允许一次”始终禁用。现在浏览器通道仅使用原网站来源授权；聊天卡分别使用本次请求的 `preflight`。旧 Host 没有该字段时才回退到原状态。原生本机和远程 Mac 缺权时仍禁止同意，拒绝保持可用。

Cordis 对公开 Service 的每次 `ctx.get()` 查询返回新的跟踪包装。旧验收读取路由把包装对象的引用变化误判为连接被替换，真实 Host 稳定报 `OWNER_CHANGED`。现在通过 Cordis 公开的 `symbols.original` 比较精确原服务，注册调用仍使用跟踪包装。另一真实服务即使复用相同 peer 和 principal，也仍被拒绝；请求取消、provider 生命周期和每次异步后的身份检查保持。

- 真实 React DOM 新增六项回归，覆盖浏览器允许一次、重复点击仅一个决定、跨聊天与不同设备预检、原生缺权拒绝和权限刷新。旧实现实际复现四项失败，修复后相邻界面40项通过。
- 真实 Cordis Context、HostConnectionService 和 SharedFetchHandler 新增七项回归。旧实现的两个真实服务正例失败，修复后通过；服务、peer、principal 和 principal kind 更换的反例均拒绝。
- 当前完整直接回归1178/1178，110个测试文件，零跳过、取消或待办；常规 TypeScript 和 H1 公开 SDK 独立严格类型检查通过。该完整回归绑定440份源码输入，测试前后源码、Git HEAD和正式组件字节及身份保持一致。

新Mac候选的真实隔离Host已完成：当前主Agent的十个公开工具调用、真实页面点击“允许一次”、真实浏览器动作、同一attempt的两张实际图片记录，以及缺少独立业务验证器时保持 `inconclusive`。这轮使用确定性SDK适配器，不是外部DeepSeek推理。
