# 会话内操作环境与跨窗口文件交换验收

本次把电脑操控的高级环境表单从设置页移入当前聊天输入框工具栏。默认使用这台电脑，需要独立浏览器或远端电脑时直接在会话中选择、配置并确认，无需再次关联聊天。设置页保留总开关、系统权限、应用授权和任务概览。

## 实现与行为

- 使用官方公开 `conversation.input.left` 会话插槽，位置在权限模式按钮旁；按插槽的 `sessionId` 调用 Host，不使用全局当前聊天席位。
- 菜单采用工具箱颜色、圆角、阴影和三种图标卡片，跟随浅深色主题。向上展开，窗口变化时重新定位，窄窗口内部滚动。
- 打开菜单或准备草稿不会建立连接。明确点击“使用此环境”才连接，成功回读后关闭；失败留在当前菜单显示原因。
- 配对草稿不跨聊天、禁用或弹层关闭保留。输入法组合期间按 Escape 不关闭菜单，普通 Escape 返回入口焦点。
- 连接和状态回执均有生命周期保护，旧聊天迟到回包不能刷新、关闭或解锁新聊天。
- 手动文件交换迁入实际远端环境菜单，必须同时匹配会话和不透明连接 ID。同一聊天在另一个窗口重连远端后，旧上传、下载或清理请求不能进入新电脑。
- 关闭菜单、切换聊天和卸载 UI 均不主动停止后台环境；明确切换环境只停止对应聊天的电脑任务。
- 连接维持在当前 Host 生命周期内；重启或闲置回收后默认本机，不持久保存配对密钥。
