# 电脑操控功能移除说明

官方 Harness 已提供相同的电脑操控功能，QiuYaTools 已移除自己的电脑操控及相关实现。请在官方 Harness 中使用该功能，授权和权限设置也由官方功能管理。

## 本次移除

- 电脑操控设置页、聊天环境选择、工具注册与路由。
- macOS 和 Windows 的桌面捕获、鼠标键盘控制、实时预览、远端执行器及浏览器配套扩展。
- 依赖电脑操控的浏览器工作台、画面批注、网页诊断、自动验收与模板，以及相关测试、验收脚本和文档。
- 发布包中的电脑操控程序和启动脚本。

## 升级与保留功能

旧版工具箱更新器可能仍要求旧的电脑操控程序；遇到更新包校验失败，请通过官方 Harness 插件管理直接安装新包并重启。

旧配置中的 `computerUseEnabled` 已停用，加载配置时会忽略该字段。插件不迁移旧电脑操控授权，也不清理用户电脑上的历史数据或远端文件。

会话独立窗口继续保留，其原生组件只用于打开聊天窗口。计划与会话文字批注、附件增强、批量归档、提示词建议、Git 管理、Q 主题和更新功能继续保留。

## bluefish 配置报错

`qThemeId` 报错列表中只有七款旧主题、缺少 `bluefish` 时，说明当前加载的 Host 配置校验仍是旧版本。新构建的 Host 与客户端使用同一份主题列表，包含 `bluefish`，并支持保存和恢复其动态或静态设置。

更新插件后，完全退出并重新打开 Harness，确保新 Host 和客户端一起生效。无需手动删除 `bluefish` 配置。
