# QiuYa 增强工具箱

让 DeepSeek Harness 更顺手：长文本附件、会话分窗、计划批注，以及可在聊天中调用的电脑操控。

**0.6.1 开发中，尚未发布。** 本版统一修复 Mac / Windows 从仓库地址或 npm 安装时缺少原生组件的问题，电脑操控默认开启。已发布的完整平台安装包见 [Releases](https://github.com/z1223473749/dsh-QiuYaTools/releases)。

## 安装

### GitHub 安装

1. 在 Harness 的 **插件 → 添加插件** 中输入 `https://github.com/z1223473749/dsh-QiuYaTools`，点击安装。
2. 安装器根据 Harness 所在系统和进程架构，安装同版本的预编译原生组件。无需编译、安装 SDK 或手动启动执行器。

也可从 [GitHub Releases](https://github.com/z1223473749/dsh-QiuYaTools/releases) 安装完整 `.tgz`：Windows 选择与 Harness 进程架构一致的 **ARM64** 或 **x64** 包，Mac 使用 **universal** 包。完整包内置原生组件，不重复下载平台依赖。下载到本地后的安装步骤见[使用指南](docs/computer-use-guide.md)。

### npm 安装（Mac / Windows）

npm 与仓库地址安装使用相同的平台组件依赖。安装时请保留可选依赖；若网络或安装策略跳过了组件，设置页会明确提示安装不完整，可重新安装或使用对应系统的完整 `.tgz`。

1. 打开 Harness 的 **插件 → 添加插件**。
2. 输入 npm 包名 **`dsh-qiuya-tools`**，点击安装。[查看 npm 包](https://www.npmjs.com/package/dsh-qiuya-tools)。

安装后点击 **立即启用**，进入 **设置 → QiuYaTools**；左下角账号菜单也有快捷入口。各渠道的可用版本与平台包以对应发布页为准。

## 功能

| 功能 | 使用体验 |
| --- | --- |
| 电脑操控 | 在聊天中说明任务，AI 发现应用并申请授权后，查看画面、点击和输入。支持 Mac、Windows、独立浏览器与已配对的远端电脑。 |
| 多任务与实时预览 | 同一聊天最多保留 8 个电脑任务。小预览可切换任务、在窗口内移动或单独弹出；悬停后显示暂停、接管、继续和停止。 |
| 长文本附件 | 长文本粘贴时自动转为 TXT，默认阈值为 1000 字符或 15 行，可自行调整。 |
| 会话独立窗口 | 右键打开，或把会话拖出列表；再次打开会唤起已有窗口。 |
| 批量归档 | Shift 连选、⌘ / Ctrl 多选后归档，也可归档工作区内的全部会话。 |
| 计划批注 | 选中文字添加评论、提交修改建议，同时保留输入框草稿。 |
| 会话批注 | 选中回复文字添加批注，正文显示编号，悬停查看意见；汇总后可单独提交并保留草稿，或加入输入框随文字、引用和附件发送。选中文字也可“新会话提问”，将原文带入同工作区的新会话草稿。 |
| 会话菜单 | 置顶、标记已读或未读、复制标题和路径、打开目录。 |
| 提示词建议 | 根据当前会话推荐下一句，按 Tab 填入、Esc 隐藏，修改后手动发送。 |
| Q 主题「鲸与海」 | 鲸鱼与白发少年的手绘背景，搭配浅色、深色半透明界面。 |
| 自动验收与模板 | 创建检查清单、保存模板、在当前聊天运行并查看结果与历史。 |
| 画面批注与网页诊断 | 将框选、箭头和修改建议发回聊天；网页日志与网络信息按需授权。 |

## 在聊天中使用电脑操控

1. 在 **QiuYaTools → 电脑操控** 开启功能。
2. 回到聊天，直接说出任务，例如“帮我打开浏览器，整理这个页面”。无需手动关联聊天或预选窗口。
3. 根据授权卡选择 **允许一次 / 始终允许 / 拒绝**，随后通过小预览查看进度，随时暂停或接管。

需要独立浏览器或远端电脑时，在当前聊天输入框旁的环境菜单中选择。各任务分别保存目标与授权；停止一个任务不会结束其他任务。同一实际桌面的鼠标和键盘操作会按顺序执行。

**始终允许的应用**支持名称搜索和图标辨认，可在设置中添加或撤销。授权由你确认，AI 不会替你开启系统权限。

## 更新与兼容

- 目前适配 Harness **0.2.1-rc.2**。Mac 原生组件以 **macOS 13+** 为构建目标，提供 Apple Silicon / Intel universal 包；Windows 提供 **ARM64 / x64** 包，独立窗口需要 Microsoft Edge WebView2 Runtime。
- Mac 首次使用需给 **DeepSeek Harness** 开启屏幕录制、辅助功能和输入监控。工具箱由 Harness Host 直接启动执行器，使用宿主的系统权限；授权卡会自动核验并显示当前宿主应用，返回工具箱后自动检测。无需为插件单独申请 Developer ID 或修改权限配置。
- 原生桌面操作需要可交互的桌面；Chrome / Edge 独立浏览器通道支持后台页面操作。
- 在 **QiuYaTools → 版本更新** 中检查更新。提示词建议使用当前会话模型，会产生少量额外模型用量。

更多配置、权限说明与使用方法见[电脑操控指南](docs/computer-use-guide.md)。
